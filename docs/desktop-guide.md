# 拾回 0.2.0 · Windows 桌面测试版

拾回帮助你查找 NTFS 磁盘上的误删文件，包括直接删除、误删目录，以及清空回收站后仍有残留记录的文件。扫描、预览和导出都在本地完成，无需账号，不收取恢复费用。

## 启动

适用系统：Windows 11 x64（Intel / AMD）。完整解压 `ShiHui-0.2.0-windows-x64.zip`，双击 `Start-ShiHui.cmd`。包内自带 Python、Qt 界面和恢复引擎，不需要另装 Python 或用 pip 安装依赖。不要直接在压缩包里运行，不要单独移动启动文件。

准备直接扫描磁盘时，请先把软件解压到**另一块物理磁盘**。例如恢复电脑内置盘上的文件，可把软件和结果放在外接盘上；同一硬盘的 C、D 两个分区不满足这一要求。镜像恢复可以使用普通工作文件夹。

`Check-Package.cmd` 会核对包内文件，并检查 Qt 与恢复引擎能否启动，不会扫描真实磁盘。`Create-Desktop-Shortcut.cmd` 可创建桌面快捷方式，创建后保持软件文件夹的位置不变。测试版未做代码签名。

## 找回文件

1. 在“开始恢复”选择来源。“Windows 磁盘”会列出带盘符的 NTFS 卷；“镜像文件”接受 `.img`、`.dd`、`.raw`，自动识别分区。
2. 选择工作文件夹，扫描记录将保存在这里。直接磁盘扫描需要管理员权限，可点击“以管理员身份重新启动”。
3. 点击“开始查找”。处理期间可以取消；大镜像会先后核对完整数据，可能需要一些时间。
4. 在结果中搜索名称、原路径或选择文件类型。点击一行可查看信息；勾选框决定哪些文件需要保存。“选择当前结果”会勾选当前筛选中的文件。
5. 可先预览文字、常见图片或 Office 文档中的文字，再点击“保存选中的文件”，选择目标文件夹。
6. 在保存结果页打开结果位置，检查重要文件。软件每次创建新目录，不覆盖上一轮结果。可从“打开扫描记录”重新打开 `session.json`。

直接扫描时，软件会核对工作目录、程序、扫描记录和恢复目标所在磁盘。无法确认物理磁盘或发现与源盘相同时会停止。Windows 自身可能继续写入正在使用的源卷；软件不会冻结系统卷。

## 看懂结果

“候选文件”表示找到了删除记录，不保证内容仍然完整。原名来自文件系统记录，或由残留的回收站索引关联；索引缺失时会显示“原名待确认”。记录被重用、文件数据被覆盖或 SSD 已执行 TRIM，都可能导致内容缺失。

恢复文件位于结果目录的 `files` 子目录，尽量保留中文名称和原目录。重名文件自动添加后缀；不安全或过长的路径片段会调整，报告保留原始记录。`recovery.json` 记录每个文件的实际路径、长度、SHA-256 和异常原因。

| 状态 | 含义 |
| --- | --- |
| 已导出 · 待检查内容 | 数据已按记录长度导出；尚未与删除前原件对照 |
| 部分结果 | 长度不符、提取异常或取消，保留已读取的部分 |
| 未完成 / 已跳过 | 查看报告原因，如空间不足、读取失败 |
| 来源发生变化 | 镜像内容或磁盘身份发生变化，结果需要重新评估 |

支持文字、PNG/JPEG/GIF/BMP/WebP/TIFF 预览，以及 DOCX/XLSX/PPTX/ODT 文字摘录。Office 预览不还原排版，不执行宏。无法解码时显示字节或错误信息；其他格式仍可导出。单文件预览上限 32 MiB，导出没有收费容量门槛。

## 当前支持范围

本版完整提供“选择来源—扫描—筛选—预览—保存—查看报告”的 NTFS 桌面流程。只处理有残留元数据的未命名数据流；候选数量上限 100,000，已删除目录最多额外遍历 2,000 个，每个引擎调用最多 10 分钟。遇到上限或损坏会在提示/报告中说明。

暂不支持 FAT/exFAT/APFS、内容深度扫描、BitLocker/EFS 解密、硬件损坏修复、逆转 TRIM、断点续扫。取消后可保留已有文件；下一次导出从新的结果目录开始。

开发环境已用真实 NTFS 镜像验证桌面扫描、预览和导出。**本包尚未在 Windows 11 真机执行**，管理员启动、原始卷访问及真实清空回收站效果属于本轮真机验收内容，不能据此承诺恢复率。

## 出现问题

- 启动失败：运行 `Check-Package.cmd`，保留输出；完整解压到较短的路径后再检查。检查失败不会删除文件。
- 没有列出磁盘：确认是 NTFS、已解锁且有盘符，再以管理员身份刷新。首版不枚举无盘符分区。
- 提示同一物理磁盘：将整个软件包、工作目录和目标换到另一块磁盘。
- 找不到文件：清除筛选，查看扫描说明；删除记录可能已被覆盖，当前没有深度内容扫描。
- 取消或保存失败：保留扫描目录和结果目录。报告包含原文件名、路径等信息，分享前先检查是否含个人信息。

如需用合成文件验收，`validation/New-RecoveryFixture.ps1` 可生成隔离的 NTFS 虚拟盘及删除镜像，流程见 `validation/windows-testing.md`。普通恢复不需要运行这个脚本。
