# 拾回 0.3.0rc2 · Windows 软件候选版

拾回帮助你查找 NTFS / exFAT 磁盘上的误删文件，包括直接删除、误删目录，以及仍有残留记录的回收站文件。扫描、预览、导出和镜像采集都在本地完成，无需账号，不收取恢复费用。

## 启动

适用系统：Windows 11 x64（Intel / AMD）。完整解压 `ShiHui-0.3.0rc2-windows-x64.zip`，双击 `Start-ShiHui.cmd`。包内自带 Python、Qt 界面和恢复引擎，不需要另装 Python 或用 pip 安装依赖。不要直接在压缩包里运行，不要单独移动启动文件。

准备直接扫描磁盘时，请先把软件解压到**另一块物理磁盘**。例如恢复电脑内置盘上的文件，可把软件和结果放在外接盘上；同一硬盘的 C、D 两个分区不满足这一要求。镜像恢复可以使用普通工作文件夹。

`Check-Package.cmd` 会核对包内文件，并检查 Qt 与恢复引擎能否启动，不会扫描真实磁盘。`Create-Desktop-Shortcut.cmd` 可创建桌面快捷方式，创建后保持软件文件夹的位置不变。测试版未做代码签名。

## 找回文件

1. 在“开始恢复”选择来源。“Windows 卷”列出带盘符的 NTFS / exFAT 卷；“镜像文件”接受 `.img`、`.dd`、`.raw`，自动识别分区。“整盘镜像采集”列出物理磁盘，先采集再扫描。
2. 选择工作文件夹，扫描记录将保存在这里。直接磁盘扫描需要管理员权限，可点击“以管理员身份重新启动”。
3. 镜像模式可勾选 PNG / JPEG 深度查找；JPEG 可进一步尝试碎片重组。NTFS 还可选择旧日志恢复。点击“开始查找”。处理期间可以取消；大镜像会先后核对完整数据，可能需要一些时间。窗口较小时页面可以滚动，导航与取消按钮保持可见。
4. 在结果中搜索名称、原路径或选择文件类型。点击一行可查看信息；勾选框决定哪些文件需要保存。“选择当前结果”会勾选当前筛选中的文件。
5. 可先预览文字、常见图片或 Office 文档中的文字，再点击“保存选中的文件”，选择目标文件夹。
6. 在保存结果页打开结果位置，检查重要文件。软件每次创建新目录，不覆盖上一轮结果。可从“打开扫描记录”重新打开 `session.json`。

直接扫描时，软件会核对工作目录、程序、扫描记录和恢复目标所在磁盘。无法确认物理磁盘或发现与源盘相同时会停止。Windows 自身可能继续写入正在使用的源卷；软件不会冻结系统卷。

## 看懂结果

JPEG 内容结果保存在 `files/Carved/JPEG/`。碎片结果显示“JPEG 碎片重组·待核对”，预览也提示可能错误拼接。基线 JPEG 校验熵编码结构；渐进式 JPEG 只检查标记、表与扫描顺序，不用于碎片重组。能解码不等于与删除前照片相同，请逐张核对；原名与目录仍未知。

“候选文件”表示找到了删除记录或符合支持格式的内容，不保证与删除前原件相同。原名来自文件系统记录，或由残留的回收站索引关联；索引缺失时会显示“原名待确认”。记录被重用、文件数据被覆盖或 SSD 已执行 TRIM，都可能导致内容缺失。

PNG 深度扫描结果显示“深度扫描·生成名称”和“原目录未知”，保存在 `files/Carved/PNG/`。名称中的编号来自镜像字节位置，不是原文件名。块结构与 CRC 校验通过不代表已验证原件一致；候选可能与普通结果重复，也可能是其他文件内嵌的图片。可以照常预览、勾选、保存和重新打开扫描记录。

旧日志结果显示“旧日志·历史名称”；缺少父目录证据时仍显示原目录未知。有缺口的结果显示“旧日志·不完整片段”，名称附“（片段）”，预览说明原文件大小及片段起始位置。保存文件名包含 `.fragment-`，状态始终为“部分结果”，不计为完整恢复。历史名称和日志关联也需要核对。

恢复文件位于结果目录的 `files` 子目录，尽量保留中文名称和原目录。重名文件自动添加后缀；不安全或过长的路径片段会调整，报告保留原始记录。`recovery.json` 记录每个文件的实际路径、长度、SHA-256 和异常原因。

源卷断开时会停止后续文件，并保留已写出的部分结果。保存页会列出失败原因和未处理数量；若目标磁盘无法写入报告，会尝试将报告存到扫描记录目录，并显示实际位置。取消管理员授权会保留当前窗口、扫描记录和选择。

| 状态 | 含义 |
| --- | --- |
| 已导出 · 待检查内容 | 数据已按候选长度导出；尚未与删除前原件对照 |
| 部分结果 | 已明确为不完整片段，或长度不符、提取异常、取消，保留已读取的部分 |
| 未完成 / 已跳过 | 查看报告原因，如空间不足、读取失败 |
| 来源发生变化 | 镜像内容或磁盘身份发生变化，结果需要重新评估 |

支持文字、PNG/JPEG/GIF/BMP/WebP/TIFF 预览，以及 DOCX/XLSX/PPTX/ODT 文字摘录。Office 预览不还原排版，不执行宏。无法解码时显示字节或错误信息；其他格式仍可导出。单文件预览上限 32 MiB，导出没有收费容量门槛。

## 当前支持范围

本版提供 NTFS / 标准单 FAT exFAT 的完整桌面流程。普通扫描使用残留删除记录；内容扫描检查镜像未分配空间，PNG 最大 256 MiB，JPEG 最大 64 MiB / 4000 万像素。JPEG 基线碎片重组最多 8 MiB、顺序空闲段最多 32 段；两段搜索限制为前 8 个头部簇边界及 4 MiB 内最近的 128 个空闲尾部簇，可能找不到其他布局。候选合计上限 100,000，删除目录最多额外遍历 2,000 个，每个引擎调用最多 10 分钟。达到边界会明确记录或报错。

暂不支持 FAT12/16/32、TexFAT、APFS、任意格式的碎片重组、APNG 动画内容扫描、BitLocker/EFS 解密、硬件维修和逆转 TRIM。内容深度扫描只读取镜像，不处理已分配簇和文件尾部空隙。导出取消后保留已有文件，下一次导出使用新目录。

## 制作镜像与继续中断任务

选择文件、Windows 卷或整盘，设置工作文件夹，点击“创建只读镜像”。默认每次读取等待最多 30 秒，失败区域缩小到扇区后额外重试 1 次；设置范围分别为 1–300 秒、0–10 次。先采集正常区域，再处理失败区域。源设备只读打开，输出为新目录中的 `image.img` 和 `acquisition.json`。

采集页分别显示已读取、坏区、待读取字节。最终坏区写入零占位，不能算作恢复数据；未完成区域仍未确认。可点击“继续采集 / 重试坏区”，或从侧栏“继续中断任务”打开 `acquisition.json`。续采会核对源身份及已采集区域的 SHA-256；断开、换盘或已采集内容被改动时停止。完整结束后可直接将镜像载入扫描。

镜像扫描在扫描目录保存 `scan-progress.json`。取消或进程中断后，从“继续中断任务”打开它；软件先核对完整源镜像 SHA-256，再复用完成阶段，并从保存的目录队列或 PNG/JPEG 块继续。旧日志解析以阶段为单位重跑。扫描续接要求同一软件和 TSK 版本、源文件路径及内容保持不变。实时卷扫描不续接，应先采集镜像。

升级到 rc2 时，rc1 的未完成扫描请用原 rc1 包继续，或在 rc2 中重新扫描；已经完成的扫描记录仍可打开。

只读采集不能修复硬件，也不能阻止 Windows 对正在使用的磁盘写入。坏盘错误路径已通过注入测试，实际故障硬盘和专用物理介质验收按用户安排暂缓。

旧日志恢复是实验功能，目前只处理部分 NTFS 日志格式，日志和文件记录表各不超过 64 MiB，单文件不超过 256 MiB；不处理创建时可能尚未写入的驻留用户数据。提示格式不支持时，可取消勾选旧日志后重新普通扫描。此选项只读取镜像文件。

源码已在 Windows 11 原生窗口中完成 NTFS 镜像流程，并实际验证隔离 VHD 中的直接删除和清空回收站恢复。增加 PNG 和旧日志扫描后，两组基本样本最终内容、原路径均匹配 6/8，另保留 1 份文字片段。两组扩展样本清空回收站后匹配 28/34，随后追加写入后只剩 2/34 的 PNG 内容，原目录未知。完整恢复尚未通过，结果不能推算到个人磁盘。

“选择磁盘”入口已通过只读虚拟卷的选择、预览、保存、重开和同盘拦截验证，卸载后的旧会话会拒绝继续读取。断连、满盘、权限和 UAC 取消分支通过故障注入回归；原生界面验收工具覆盖四档缩放。可写物理介质、实际拔盘、真实 UAC 取消及跨显示器切换仍待覆盖。[候选版验收与边界](milestones/10-software-completion.md)

## 出现问题

- 启动失败：运行 `Check-Package.cmd`，保留输出；完整解压到较短的路径后再检查。检查失败不会删除文件。
- 没有列出卷：确认是 NTFS / exFAT、已解锁且有盘符，再以管理员身份刷新；无盘符设备可先使用“整盘镜像采集”。
- 提示同一物理磁盘：将整个软件包、工作目录和目标换到另一块磁盘。
- 找不到文件：清除筛选，查看扫描说明；镜像中的 PNG 可尝试勾选深度查找并重新扫描。记录或内容被覆盖后仍可能无法恢复。
- 取消或保存失败：保留扫描目录和结果目录。报告包含原文件名、路径等信息，分享前先检查是否含个人信息。

如需用合成文件验收，`validation/New-RecoveryFixture.ps1` 可生成隔离的 NTFS / exFAT 虚拟盘及删除镜像，流程见 `validation/windows-testing.md`。普通恢复不需要运行这个脚本。最新功能和证据见[0.3.0rc2 验收记录](milestones/12-automated-coverage.md)，开发自动测试见[覆盖矩阵](test-matrix.md)。
