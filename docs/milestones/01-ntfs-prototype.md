# 第一个开发里程碑：NTFS 镜像恢复原型

验收日期：2026-09-12。当前完成的是可运行、可复现的命令行恢复流程；Windows 桌面产品仍在开发范围内。

## 已实现

- 只读 NTFS raw 镜像扫描，记录源镜像摘要、分区偏移、底层版本和候选证据。
- 选择候选并导出到新目录；隔离重名文件和不可信路径，保留部分、失败、跳过状态。
- 解析两版回收站 `$I` 格式，按卷内位置、SID、后缀及大小关联 `$R`；证据不足时保留未知原路径。
- 重新读取导出文件，与原件清单一对一比较，分别统计内容、名称和目录。
- 限制子进程输出、时间和诊断大小；取消时保留报告及未完成状态。

代码采用 Python 3.11+ 标准库，本次底层实际使用 TSK 4.15.0。项目代码为 MIT；TSK 保持独立外部依赖。运行方式见[开发说明](../development.md)。

## 本轮实测结果

| 检查 | 结果 | 证据范围 |
| --- | --- | --- |
| 自动测试 | 78 项通过 | 回收站格式、候选兼容性、输出边界、取消、源变化、路径保护和清单校验 |
| 公开真实 NTFS 镜像 | NIST DFR-01，分区起始扇区 61 | 官方为删除恢复制作的旧版测试镜像；不是 Windows 11 实机效果 |
| 扫描目标 | 发现 `/Bunda.txt`，NTFS 属性 `65-128-2` | 同时跳过无可用数据属性的损坏/孤立条目，不把它们计作成功文件 |
| 实际导出 | 4,296 字节，与文档指定镜像区域逐字节一致 | 参考摘要来自删除后镜像区域，未取得独立删除前原件 |
| 原路径 | 与本例登记的 `/Bunda.txt` 一致 | 仅这一公开目标；不能外推清空回收站的名称恢复率 |
| 源保护 | 扫描与导出后完整镜像 SHA-256 不变 | 仅镜像文件保护；未验证真实设备访问 |
| CLI | `scan → recover → verify` 全部退出 0 | 使用实际 TSK 执行，没有以假后端替代这次集成测试 |
